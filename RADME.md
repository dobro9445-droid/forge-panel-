# FORGE — панель игрового хостинга
Node.js + WebSocket: консоль, CPU/RAM, файлы, бэкапы, планировщик, SourceMod-шаблоны, свои игры, PWA.

## Запуск
npm install && npm start → http://localhost:8088 (admin / admin или $ADMIN_PASSWORD)

## На телефоне
Termux: pkg install nodejs git → git clone → npm install → npm start

## Облако из GitHub
Railway / Render (см. railway.json, render.yaml) или GitHub Codespaces (.devcontainer).
